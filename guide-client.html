Guide client

Commander avec YILGA

Six étapes, avec les écrans de l'application. De la création du compte à la note du prestataire.

  1. 1Compte
  2. 2Recharge
  3. 3Commande
  4. 4Suivi
  5. 5Confirmation
  6. 6Note
1

Créez votre compte

Entrez votre numéro de téléphone, tapez le code reçu par SMS, puis choisissez un code secret à six chiffres. Pas d'adresse email, pas de mot de passe à retenir.

Ensuite, l'empreinte ou le visage suffit pour ouvrir l'application au quotidien.

2

Rechargez votre portefeuille

Choisissez un montant et votre opérateur, Orange Money ou Moov Money, puis composez le code USSD affiché. Votre solde est crédité dès la confirmation du paiement.

Vous préférez les espèces ? Vous pouvez aussi payer le prestataire à la remise, ou recharger chez un agent YILGA.

3

Commandez

Pour une livraison : ce que vous envoyez, la taille du colis, le point de retrait et le point de livraison. Pour un ménage : une prestation du catalogue, à prix fixe. Le prix s'affiche avant de confirmer.

Vous choisissez à ce moment entre le portefeuille et les espèces.

4

Suivez la course

Placez vos points sur la carte ou choisissez un quartier, puis suivez la commande étape par étape. Dès qu'un prestataire accepte, vous voyez son nom et pouvez l'appeler.

Une notification vous prévient aux étapes clés.

5

Confirmez, ou contestez

Une fois la prestation clôturée, vous disposez d'un délai affiché pour confirmer ou signaler un problème. Sans contestation, le paiement part tout seul et votre reçu numérique est disponible.

En cas de litige, une personne de YILGA examine les deux versions et tranche.

6

Notez le prestataire

Une note de une à cinq étoiles, une seule fois par commande terminée. Elle construit la réputation de celui qui est venu et guide les prochains clients.

Votre historique garde chaque commande, avec son reçu.

Prêt à commander ?

L'application YILGA pour Android s'installe en quelques minutes. Vous êtes livreur ou agent de ménage ? Voir le guide prestataire.
